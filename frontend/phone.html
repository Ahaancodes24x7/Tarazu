Device

Engine

The screen is served by the Tarazu server on this computer. To preview the offline app build, where the engine runs inside the phone with no network, start it with python tools/serve_app.py.

Open it on your own phone

Start the server with HOST=0.0.0.0, connect the phone to the same Wi-Fi and open http://<this computer's address>:8000/app.html. For the installable Android app, see DEMO.md.
